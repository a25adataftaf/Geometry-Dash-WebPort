GEOMETRY DASH

port de Lollipop

Cubo, pinchos, y la música a todo volumen: el webport que se juega directo en el navegador. Todos los ficheros del juego se sirven desde GitHub, así que no hay nada que instalar.

Ver requisitos
  • ~370 MB la primera carga
  • Chrome / Edge con JSPI
  • Progreso guardado en el navegador

Antes de jugar

Navegador

Chrome o Edge actualizados. El juego usa JSPI (WebAssembly con promesas); si no arranca, entra en chrome://flags, activa Experimental WebAssembly JavaScript Promise Integration (JSPI) y reinicia el navegador.

WebGL 2

Hace falta aceleración por hardware. En Windows: Ajustes → Sistema → Pantalla → Gráficos y deja que Chrome use la GPU. Sin WebGL 2 el canvas se queda en negro.

Descarga inicial

El runtime pesa unos 370 MB (data + wasm en trozos). Se descarga la primera vez, así que dale un poco y no cierres la pestaña en mitad de las barras WASM / DATA.

No inicies sesión

Las funciones en línea (cuentas, niveles, listas) pasan por un proxy de terceros que no controlamos. Juega en local y no metas tus contraseñas.

Cómo jugar

  1. 1 Pulsa JUGAR y espera la pantalla del webport.
  2. 2 Toca el botón LOAD del centro de la pantalla.
  3. 3 Mira las barras WASM y DATA: son los 370 MB de la primera vez. Luego arranca el juego solo.
  4. 4 En el juego: Espacio, ↑, clic o toque para saltar. En la barra de abajo tienes pantalla completa, FPS y Clear cache.

Si algo va raro, abre el port con ?debug al final de la URL (por ejemplo /play/?debug) para ver la consola del motor.

Modo local (sin CDN)

Por defecto el port baja los ficheros desde el CDN de GitHub (jsDelivr). Si prefieres tenerlos en tu equipo —para jugar sin depender de internet o para publicarlos tú— hay un script que los trae todos: 

npm run juego:descargar

Los guarda en public/geo/ (no se suben a Git) y el port detecta solo si están ahí: verás «ficheros locales» en la pantalla de inicio y ya no tocará el CDN durante la partida.

Comprobando si tienes los ficheros locales…
